# Installation

From the source repository:

```bash
git clone https://github.com/Aayush9808/InfraScan.git
cd InfraScan
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The release candidate requires a compatible checkpoint at `weights/best.pt` for trained-model workflows. Obtain it only from a source you are authorized to use; no download URL is asserted.
