# GLBITM poster template audit

**Source file:** `GLBITM POSTER Format.pptx` (workspace root, not committed)
**Audited:** 22 October 2026
**Page size:** 10.50 × 14.00 in (portrait)
**Structure:** one slide, nine labelled regions
**Theme fonts:** Calibri Light / Calibri
**Institutional line:** “SESSION (2026-2027) BATCH – 2023 · Final Year Project Evaluation”

## Region map

The template is a three-column grid with a header band and a lower workflow band.

| Region | Approximate position | Template label | InfraScan content |
|---|---|---|---|
| Header | full width, top | Session / batch / evaluation | Keep exactly; check the session |
| Identity | left, upper | Group ID | `[TO BE CONFIRMED]` |
| Abstract | centre, upper | Abstract | 90–120 word summary |
| Introduction | right, upper | Introduction | 80–110 words |
| Methodology | left, middle | `Methodol / ogy` (template typo) | 90–120 words + model setup |
| Objectives & Motivation | right, middle | Objectives & Motivation | 4 bullets |
| Experimentation & Results | left, lower | Experimentation & Results | Metrics table + one figure |
| Conclusion | centre, lower | Conclusion | 60–90 words |
| References | right, lower | References | 4–6 compact entries |
| Workflow Diagram | full width, bottom | Workflow Diagram | horizontal pipeline graphic |
| Title block | top of centre/right | Project Title / Team / Supervisor | title, four names, supervisor |

The template's spelling error `Methodol / ogy` should be corrected to **Methodology** in the final poster. Keep the institutional header, column structure and footer identity.

## Typography

| Element | Suggested size | Notes |
|---|---:|---|
| Project title | 36–44 pt bold | Must be readable from 2–3 m |
| Author names | 20–24 pt | Roll numbers on a second line |
| Section headings | 24–28 pt bold | Match template heading style |
| Body | 16–18 pt | Never below 16 pt for a printed poster |
| Tables | 14–16 pt | Fewer rows, larger text |
| Captions | 13–15 pt italic | One line if possible |
| References | 12–14 pt | Four to six entries |
| Footer | 12–14 pt | Keep institutional line |

Use **Calibri Light** for the title/headings and **Calibri** for body text, matching the template theme. If the print shop lacks Calibri, export a PDF with embedded fonts rather than substituting silently.

## Colour and imagery

- Retain the template's institutional colours and header/footer treatment.
- Use one restrained accent (teal or blue) for the pipeline arrows and metric highlights.
- Use a white or very light panel behind body text; avoid the dashboard's dark theme across the whole poster.
- Use at most **two** screenshots and **one** diagram. A poster crowded with UI chrome is unreadable.
- Crop screenshots to the meaningful panel; keep aspect ratio; add a thin border.
- Do not place a screenshot over text or reduce it below the point where labels are legible.

## Content constraints

- The abstract must stand alone: problem, method, result, limitation.
- The introduction must not repeat the abstract word for word.
- The methodology should name the actual stack: YOLO11n, FastAPI, SPA, shared severity, video job.
- Results must use the verified 718-image run and the correct evaluation environment.
- The conclusion must include a limitation, not only a success statement.
- The workflow diagram should fit in the lower band and be readable without a magnifier.
- The poster is **not** a place for a full literature review; four to six references are sufficient.

## Poster QA checklist

- [ ] Group ID and supervisor fields filled or clearly marked `[TO BE CONFIRMED]`.
- [ ] All four names and roll numbers spell-checked.
- [ ] Title and subtitle fit the header without overlapping the template line.
- [ ] Every section has body text; no empty template placeholders.
- [ ] Metrics match [`../PROJECT_FACTS.md`](../PROJECT_FACTS.md).
- [ ] Screenshot captions state what the image proves.
- [ ] Workflow arrows point in the correct direction.
- [ ] No text below 12 pt; body at least 16 pt.
- [ ] No clipped text at the print margins.
- [ ] PDF exported with embedded fonts.
- [ ] Printed proof checked at 100% scale.
- [ ] Poster can be read from 2 m for the title and 1 m for body text.
