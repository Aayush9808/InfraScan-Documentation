# Technical glossary

- **Bounding box:** Rectangle locating an object.
- **Confidence:** Model score associated with a predicted detection.
- **IoU:** Overlap ratio between predicted and reference boxes.
- **NMS:** Non-maximum suppression; removes redundant overlapping detections.
- **Precision:** Fraction of predicted positives that are correct.
- **Recall:** Fraction of reference positives detected.
- **mAP:** Mean average precision across classes and thresholds.
- **Inference:** Running a trained model to produce predictions.
- **Checkpoint:** Saved model parameters used for inference or continued training.
- **Telemetry:** Structured detection records such as frame, confidence, and coordinates.
