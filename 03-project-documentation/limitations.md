# Limitations

- The public release does not include `weights/best.pt` or `dataset/`.
- Dataset and checkpoint redistribution permissions are unresolved.
- Fresh accuracy, recall, mAP, latency, and calibration results are not certified by this documentation repository.
- Camera testing depends on local hardware and permissions.
- Visual pothole detection can be affected by lighting, weather, occlusion, road texture, camera angle, and domain shift.
- A bounding box does not measure pothole depth or structural risk.
- Ultralytics licensing must be reviewed for the intended distribution and use.
