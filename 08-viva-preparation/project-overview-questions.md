# Project overview questions

1. **What is InfraScan?** A pothole-detection workflow integrating Ultralytics inference with a Streamlit dashboard.
2. **What problem does it address?** Visual screening of road imagery.
3. **What are the inputs?** Image, video, and camera-oriented sources supported by the implementation.
4. **What are the outputs?** Annotated media and supported telemetry.
5. **Is it production-certified?** No.
6. **Why document limitations?** To define valid interpretation.
7. **Who is the upstream author?** Bisman Singh, as preserved in the source attribution.
8. **Who maintains InfraScan?** Aayush Kumar Shrivastav.
9. **Why is the model excluded?** Redistribution permission is unverified.
10. **What is the main technical contribution?** Integration and dashboard/inference workflow work, not invention of YOLO.
