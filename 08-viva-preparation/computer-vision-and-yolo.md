# Computer vision and YOLO questions

1. Detection differs from classification because it returns locations.
2. A box is commonly represented by center coordinates, width, and height.
3. IoU measures overlap.
4. NMS suppresses duplicate predictions.
5. Precision penalizes false positives.
6. Recall penalizes missed objects.
7. mAP aggregates precision-recall performance.
8. Inference is not training.
9. A checkpoint stores learned parameters.
10. Confidence is not guaranteed probability calibration.
11. Augmentation improves variation but can introduce unrealistic samples.
12. Domain shift reduces generalization.
13. A detector cannot infer pothole depth from a box alone.
14. More model capacity can increase compute requirements.
15. Input resolution affects detail and speed.
