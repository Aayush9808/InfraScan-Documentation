# Training and evaluation

`train.py` and `evaluate.py` are present in the source repository. Their workflows require an authorized dataset and compatible checkpoint/configuration. The public documentation repository does not claim that a new training or evaluation run was performed.

For a reproducible experiment, record:

- Python and package versions.
- Model variant and initialization source.
- Dataset version and license.
- Train/validation/test split.
- Image size, epochs, batch size, device, and random seed.
- Checkpoint hash.
- Metrics, logs, and evaluation command.
