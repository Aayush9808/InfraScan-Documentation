# Dataset provenance

The public source repository's inherited documentation describes a multi-source pothole dataset, but the release candidate excludes the actual dataset and does not contain sufficient independent evidence to certify every source, count, or license.

Required confirmation:

- Original dataset names and creators.
- Stable source URLs.
- License and redistribution terms.
- Permission for derived labels and processed copies.
- Exact split counts used for the checkpoint.

Do not distribute or cite a dataset as freely reusable until these items are verified.
